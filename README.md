# Wildfire_Regimes_W11
This repository contains code used for statistical analysis and visualization of wildfire trends in important water supply watersheds in the western United States.


## Data

Prior to any analysis it is assumed that the following files have already been downloaded:

- USGS Watershed Boundary Dataset
- National Interagency Fire Center Historical Fire Perimeters
- ECMWF ReAnalysis v5 grib rile for runoff and precipitation
- EPA Ecoregion Level 3 shapefiles
- Forests 2 Faucets Dataset


## Scripts
The backbones for this code are python packages: Geopandas, xarray, matplotlib. Helper functions are located in the pycollections folder
